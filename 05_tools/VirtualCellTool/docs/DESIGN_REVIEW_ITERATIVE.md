# 基因筛选方案 · 三轮迭代设计评审记录

> 评审对象：**SIGnature（SCimilarity 归因）+ GEARS（因果扰动）的"双向验证"基因筛选方案**
> 评审方法：每轮 = 以 iGEM 评委视角提问 → 以团队身份诚实自答 → 定位缺口 → 应用修改。连续三轮。
> 对应代码：`src/v2_closed_loop.py`（v1→v2 闭环）、`src/compute_ms_attribution.py`（v1 归因）

---

## 评审前状态（v2.0）

`v2_closed_loop.py` 用 **CEBPA** 验证 GEARS 加载/基因顺序正确（pearson r=0.972），并据此声称
"位移 0.338 是 v1 单基因扰动 0.01 的 34 倍，证明 v1 无级联效应、需要 v2 补足"。
本记录证明该结论不成立，并给出修正架构。

---

## 第 1 轮：方案定义与数据流

### 1.1 评委提问

- **Q1**："双向验证"到底验证什么？谁是"筛"、谁是"验"、结论对象是谁？v2 的输出有没有反哺去修正 v1 的排序？
- **Q2**：闭环在真实疾病候选基因上闭合了吗？v1 筛出 FTL/ASPA，但 GEARS 只认 Norman 扰动图（K562 转录因子），FTL/ASPA 不在 `pert_list`。跑通的 CEBPA 与 MS 少突胶质零关系。
- **Q3**：用 K562 的因果模型去"验证"CNS 细胞的归因，生物学前提是什么？
- **Q4**：0.338（v2，K562）vs 0.01（v1，B 细胞）是同一把尺子吗？

### 1.2 团队自答（暴露的缺口）

- **G1**：没有真正双向验证——v2 只证明了 GEARS 加载正确，没验证归因方案。
- **G2**：数据流断点——疾病候选基因喂不进 GEARS，闭环未闭合。
- **G3**：跨域无前提，K562→CNS 因果迁移不成立。
- **G4**：尺度不可比，"34 倍"论证作废。

### 1.3 本轮修改

- **M1**：确立两层架构——**Tier 0 方法验证层**（Norman/K562，有因果 ground truth）+ **Tier 1 应用层**（MS，无 ground truth）。
- **M2**：重新定义"双向"= 正向（precision）+ 反向（recall）两个可证伪检验，都在 Tier 0 内做。
- **M3**：GEARS 职责改为"**验证方法**"，不验证具体疾病基因。
- **M4**：CEBPA 降级为反向检验的一个数据点，不再是整个 demo。

### 1.4 修改后状态

架构：`单链 demo` → `验证层 + 应用层`。
缺口消除映射：G1→M2，G2→M3，G3/G4→M1（不再跨域比较）。

## 第 2 轮：Tier 0 验证的严谨性

### 2.1 评委提问

- **Q1（混淆变量）**：attribution 和 perturbation effect 都跟基因表达水平相关。你证明的会不会只是"高表达基因扰动效应大"？SIGnature 的核心论点就是"表达量 ≠ 重要性"，你的验证必须直接检验这一点——加表达量/随机基线，证明归因有**增量**预测力。
- **Q2（统计功效）**：Norman 有多少单基因扰动有真实敲低细胞？n 是多少？Spearman 相关够不够？
- **Q3（recall 定义）**："效应大"的阈值、recall@K 的 K 取多少？阈值选择会左右结论，需要敏感性分析。
- **Q4（方向 vs 幅度）**：归因有符号，效应是恒正位移。正向检验用 |attr| 还是带符号？符号与效应方向是否单独检验？

### 2.2 团队自答

- **G5**：缺少基线对照，相关性可能被表达水平混淆。
- **G6**：n 未统计，功效未知。
- **G7**：recall 阈值未定义。
- **G8**：符号信息未纳入。

### 2.3 本轮修改

- **M5**：正向检验加三个基线——表达量 rank、随机 rank、以及归因对表达量的**增量预测力**（partial correlation / 含表达量协变量的多元回归）。
- **M6**：明确 n = Norman 有真实敲低细胞的单基因扰动数（以实际数据统计为准，预计约百来个），据此报功效。
- **M7**：recall@K 取 K∈{10,20,50} 做敏感性；"效应大"定义为真实位移 top-10%。
- **M8**：正向检验用 |attr|（幅度）；另设**符号对齐检验**（attr 符号 vs 敲低效应方向一致性）。

### 2.4 修改后状态

Tier 0 从"算一个相关系数"升级为"**带基线的可证伪检验套件**"。

## 第 3 轮：应用层与诚实 gap

### 3.1 评委提问

- **Q1（迁移假设）**："SCimilarity 是跨组织通才，所以归因-因果相关性可迁移"——这个假设本身没被验证。能否在 Tier 0 内加跨状态/跨数据集留一验证？
- **Q2（输出规格）**：第 1 层最终交付什么？怎么防止湿实验队友把"排名第 1"当成"一定重要"？
- **Q3（假阳性率）**：若 r=0.4（中等），排名前列有多少假阳性？怎么传达正确率？
- **Q4（与 iGEM 主线连接）**：转录层面筛选的基因，但 RNA binder 调控的是**翻译**——这个 A3 gap 在应用层怎么接？

### 3.2 团队自答

- **G9**：迁移假设未验证。
- **G10**：无输出规格、无置信框架。
- **G11**：假阳性率未量化。
- **G12**：与 RNA binder 主线的转录-翻译 gap 未在方案内闭合。

### 3.3 本轮修改

- **M9**：迁移假设显式化为可检验命题 **H2**；若可用 Adamson（K562 另一套扰动）或 Norman 组合扰动做留一交叉验证。
- **M10**：定义输出规格——排序 CSV + `effect_size / attr / expr` 列 + 顶部声明"假设生成器，非因果清单"。
- **M11**：用 r 直接换算 R²，诚实呈现"排名前列仍含 X% 噪声"。
- **M12**：明确定位——筛选输出是"**靶点候选**"，转录→翻译 gap 用 A3 显式声明；"是否需要蛋白层面证据"列为待定战略问题（见待办）。

### 3.4 修改后状态

应用层有明确交付物 + 置信框架 + 诚实边界声明。

## 三轮后的最终架构（v2.1）

### Tier 0 — 方法验证（Norman/K562，有因果 ground truth）

1. 对照细胞 → SCimilarity embedding + IG 归因（28,231 空间，3536/5045 基因可映射）
2. 对每个有真实敲低细胞的单基因扰动 g，算**真实因果效应** = ‖embed(KD cells) − embed(ctrl)‖（GEARS 预测效应作补充）
3. **正向（precision）**：Spearman(attr_rank, effect) + 表达量/随机基线 + partial correlation
4. **反向（recall）**：recall@K（K=10/20/50）+ AUROC（top 效应基因 vs 随机）
5. **符号对齐**：attr 符号 vs 敲低效应方向
6. 产出可引用数字：r、p、recall、AUROC

### Tier 1 — 应用（MS 少突胶质，无 ground truth）

1. 归因 → 差异归因（Cohen's d）→ 排序清单
2. 外部验证：MS GWAS/文献已知基因富集（次级证据）
3. 输出规格：CSV + 置信声明

### 假设清单（显式）

- **H1**（Tier 0 内可检验）：K562 上归因排序与真实因果扰动效应显著相关，且**增量于表达量**。
- **H2**（迁移，弱）：该相关关系可迁移到其他细胞类型（方法迁移，非逐基因迁移）。
- **A3**（局限）：转录层面重要性对翻译层面干预只有参考价值。

### 诚实 gap（评委追问的标准回答）

- Tier 0 验证的是**方法**，不是 FTL/ASPA 这两个具体基因。
- FTL/ASPA 的因果验证三路（从强到弱）：① 湿实验 CRISPRi 敲低少突胶质；② CNS Perturb-seq 重训 GEARS；③ CellOracle/SCENIC 在 MS 数据上做同域 in silico 敲低（无 ground truth 的次级证据）。
- 标准话术："我们在 K562 上证明了归因排序与因果扰动效应显著相关（r=?, recall=?），因此把归因作为疾病数据里的筛选器；FTL/ASPA 的最终因果验证留给湿实验。"

## Tier 0 实测结果（2026-08-16，负结果）

`src/tier0_validate.py` 在 Norman/A549 上跑通（注意：cell_type 实为 **A549** 非 K562）。
n=101 个单基因敲低（映射进 SCimilarity 且有真实细胞），效应测量无 n_cells 混杂（r=0.028）。

| 指标 | 值 | 结论 |
|---|---|---|
| Spearman(归因, 真实效应) | **0.022 (p=0.83)** | 不相关 → **H1 被证伪** |
| Spearman(表达量, 真实效应) | -0.092 (p=0.36) | 不相关 |
| Spearman(随机, 真实效应) | 0.007 ± 0.093 | 零基线 |
| Spearman(归因, 表达量) | **0.862** | 此数据归因≈表达量 |
| partial Spearman(归因, 效应 \| 表达量) | 0.176 (p=0.079) | 弱、不显著 |
| recall@10/20/50 | 0.2 / 0.2 / 0.56 | 接近随机 |
| AUROC(top10% 效应) | 0.56 | 接近 0.5 |

**结论**：
1. "双向验证"假设 H1（归因≈因果重要性）被证伪，原"GEARS 验证归因"思路作废。
2. 此数据里归因≈表达量（r=0.86），与 SIGnature 论文"表达量≠重要性"头条口号在秩相关层面相悖（他们强调的是顶部几个基因不同，整体排序仍跟表达量走）。
3. 负结果与 v1 负结果（12 基因敲低不翻转类型）同源：细胞身份冗余度高 → "表征重要性" ≠ "非冗余必需性"。

**修正叙事**：归因=表征重要性筛选器（marker 恢复 + 文献/GWAS 富集验证，非因果）；GEARS=因果预测器（held-out 验证 r=0.972，域受限）。两者**互补非互验**，r=0.02 即"重要≠必需"的直接证据。
