# 在 Codex 中阅读整理后的网页

## 1. 启动预览

在仓库根目录运行：

```bash
python3 00_docs/05_preview/serve.py --port 8767
```

保持终端运行，然后打开[项目资料导航](http://127.0.0.1:8767/00_docs/01_guides/PROJECT_INDEX.html)。从首页进入各文件夹，展开需要的历史全文或逐文件表；无需逐份打开 Markdown。停止预览时，在该终端按 Ctrl+C。

HTML 在文件面板中可能显示源码；请使用上面的 HTTP 浏览器地址。默认不传 `--port` 时端口为 8765，需同步更改浏览器地址。

## 2. 预览范围

服务只监听 `127.0.0.1`，不执行页面脚本、不接受写入、不提供目录列表。它提供 `00_docs` 中的文档，以及 [DOCUMENT_PREVIEW_FILES.json](DOCUMENT_PREVIEW_FILES.json) 精确登记的公开阅读页、说明与历史展示图。

原始表达矩阵、模型权重、运行源码和本地验收大文件不通过预览服务提供。新网页对这些材料显示文件名与“在项目文件面板查看”的提示；本地完整路径与用途保存在各目录的 `INVENTORY.yaml`（不入库）。既存历史 HTML 如依赖页面脚本，只保留静态阅读效果；当前整理入口均不依赖脚本。

## 3. 无法打开时

1. **连接失败：** 检查启动终端是否仍运行；关闭后需要重新执行启动命令。
2. **端口占用：** 换一个端口，例如 `--port 8768`，并将浏览器地址同步改为 8768。不要停止用途不明的其他进程。
3. **新页面显示 404：** 旧服务可能尚未读取新白名单，重启自己的预览服务或换端口启动最新版。
4. **浏览器要求许可：** 按应用显示决定是否授权；若组织策略禁止该地址，保留策略并向管理员核实。

## 4. 维护者验证

```bash
.venv/pipeline/bin/python -m unittest discover -s 00_docs/05_preview/tests -v
```

测试使用本机临时端口，验证新页面、图片类型、HEAD、拒绝未列入的源码/数据、路径越界和 POST。新增阅读文件时更新精确白名单；不要改成任意项目文件服务器。
