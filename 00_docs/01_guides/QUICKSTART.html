第一次筛选：Williams 综合征

安装一次，运行一条筛选命令，打开结果页。

1. 你会得到什么

一次 Williams 综合征已知区间的候选排名，以及能直接用浏览器打开的结果页。数据在本次运行时下载；无需本机历史数据。

① 下载
5 份公开参考→② 提取
已知区间候选→③ 筛选
身份核对与排名→④ 阅读
网页与完整表格

2. 复制这四行

准备 Python 3.11、Git 和网络；在终端执行（macOS / Linux Bash）：

git clone https://github.com/panxuan-pku/igem-backup.git
cd igem-backup
bash scripts/setup_envs.sh --pipeline-only
.venv/pipeline/bin/python scripts/run_quickstart.py

已在仓库中时，从第三行开始。环境安装会重建本项目的 .venv/pipeline；以后只需运行第四行。 参考文件约 54 MiB，依赖安装另计。所需时间主要取决于网络。

3. 打开结果，先看这三点

成功后终端打印 report.html 的完整地址。复制地址到浏览器即可，无需启动服务器。

查看内容如何理解
候选排名排名数字越小越靠前；得分是本次配置下的相对分值，不是患病概率。
证据覆盖与空白缺少证据不等于阴性。优先查看 ClinGen 类别、gnomAD 约束和完整注释。
完整排名 CSV网页有直接下载链接，用表格软件进一步查看；不要只截取前三名当结论。

所有输入、输出和日志都在 03_pipeline/outputs_repro/quickstart_williams_运行时间/。 每次新建目录，不复用旧排名，也不会把数据纳入 Git。

4. 示例范围与数据来源

使用 GeneReviews 所列 GRCh38 chr7:73,330,452–74,728,172，保留与区间有重叠的蛋白编码基因（1-based 闭区间）。 它是一个明确边界的上手示例，不代表所有 Williams 相关基因。

来源用途
GENCODE v44基因位置和蛋白编码类型
HGNC complete set按 Ensembl 编号核对 HGNC 身份，再交叉核对符号标准化结果
ClinGen GRCh38剂量敏感性证据；原始类别单独保留
gnomAD v2.1.1 by genepLI / LOEUF 基因级约束值；不使用其坐标提取候选
HPA v24.1表达注释，不参与扣分

只运行核心筛选；不运行 CNV 推断、AI 模型或 VCT。控制基因为 []，不调参。 排名不证明因果关系或治疗效果。HGNC 和 ClinGen 会更新，结果可能随下载日期变化； 每次下载的地址、时间和 SHA256 保存在 manifest.json。

5. 如果没有完成

下载失败会重试两次，之后明确停止。恢复网络后重新运行；旧目录保留，不覆盖。 遇到身份映射或数据格式错误，请查看终端指定日志；脚本不会跳过错误输出成功报告。
