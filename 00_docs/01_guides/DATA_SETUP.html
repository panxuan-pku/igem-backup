2. 核心筛选：来源、位置与格式

所有位置均相对于仓库根目录。先创建 03_pipeline/data/ 与 03_pipeline/input/。选择版本后保存下载地址、日期和 SHA256；下面是来源入口，不承诺源站当前版本等于历史快照。

数据 从哪里获得、如何处理 本地文件和必需字段
HGNC 命名 官方自定义下载；下载 TSV，核对并统一表头 03_pipeline/data/hgnc_aliases.tsv：hgnc_id、symbol；建议包含 prev_symbol、alias_symbol、ensembl_gene_id
ClinGen 剂量敏感性 官方 FTP；取 GRCh38 gene curation list，保留注释和表头 03_pipeline/data/clinGen_gene_curation_list_GRCh38.tsv：#Gene Symbol、Haploinsufficiency Score、Triplosensitivity Score
gnomAD 约束 下载页与字段说明；历史配置针对 v2.1.1，选择兼容表后保存为 TSV 03_pipeline/data/gnomad_constraint.tsv：gene 或 gene_symbol、pLI、oe_lof_upper；不能直接替换成指标口径不同的新版本
HPA 组织表达 官方下载页中 Tissue RNA expression consensus；解压 TSV 03_pipeline/data/rna_tissue_consensus.tsv：Gene name、Tissue、nTPM
疾病候选 根据你确认的疾病文献或已知缺失区间生成，记录区间与基因组版本；不要把旧排名当输入 03_pipeline/input/my_candidates.csv：首行 gene_symbol，随后每行一个候选符号；可加 source、deletion_id、chrom、start、end
控制基因 根据本次疾病明确选择，每行一个符号；尚未设置时使用空文件 03_pipeline/input/my_controls.txt；或在本次配置中显式设 positive_controls: []。示例配置中的旧控制列表不能直接用于新疾病

历史文件指纹清单只登记本地旧快照的大小和 SHA256，便于辨认版本；它不是下载器，也不证明来源正确。若拿不到旧版本，可用明确登记的新版本重新分析，但不能声称逐值复现历史结果。候选清单同样要自行确定，旧清单不入库。

3. 安装、检查与运行

在仓库根目录运行。安装脚本会重建同名 .venv/pipeline 环境。

bash scripts/setup_envs.sh --pipeline-only
.venv/pipeline/bin/python scripts/test_pipeline.py
python3 scripts/check_release.py

工程测试使用合成输入。check_release.py 默认只检查发布源码完整性，不表示真实数据已经就绪。准备好第 2 节文件后，执行：

cd 03_pipeline
../.venv/pipeline/bin/python -m src.normalize \
  --input input/my_candidates.csv --hgnc-alias data/hgnc_aliases.tsv \
  --out outputs_repro/my_run/normalized.csv
../.venv/pipeline/bin/python -m src.merge_evidence \
  --normalized outputs_repro/my_run/normalized.csv --config config/pipeline.yaml \
  --out outputs_repro/my_run/evidence.parquet --audit outputs_repro/my_run/audit
../.venv/pipeline/bin/python -m src.consensus_v2 \
  --evidence outputs_repro/my_run/evidence.parquet --config config/pipeline.yaml \
  --mode rank --controls input/my_controls.txt \
  --out outputs_repro/my_run/ranked.csv --report outputs_repro/my_run/report.md

每次使用新的运行目录，不覆盖旧结果。该示例未接入 AI 分数，不应期待与旧的含 AI 排名完全一致；如另行准备 AI 表，先阅读技术参考的输入契约，再传 --ai-scores。DeepLOF 的正式替换和科学核对尚未完成，不能把已有代理分数描述成已运行该模型。

python3 scripts/check_release.py --with-data 检查上述四份参考表；候选路径、字段有效性与匹配问题由实际命令检查。--with-vct-data 另查 VCT 演示资源；--with-optional-data 检查历史 GEO/GEARS 的指定文件。存在性检查均不等于科学复现。
