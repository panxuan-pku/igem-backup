2. 项目背景与目标

疾病：染色体微缺失病（22q11.2DS、Williams、Angelman 等）——一大段染色体丢失，段里 20~40 个基因同时"单倍不足"（剂量减半）。

药物：RNA binder（SINEUP 式）——结合目标基因 RNA 的特定区域，上调其翻译，把剩下的等位基因补回 100% 剂量（剂量补偿）。

本报告的目标：走通一条计算通路——确定疾病 → 确定细胞类型 → 患者单细胞数据归因 → 候选基因列表 → 模拟扰动后状态验证——并诚实记录每一步的问题、思路、方法、结果与不足。

3. 通路五步：逐环节复盘

每一步均保留“问题 → 思路 → 方法 → 结果 → 不足”，点击标题展开。

第 1 步：确定疾病
  • 【问题】 ① 扰动工具 CellOracle 只能扰动 TF；② 微缺失病是多基因缺失、关键基因多数不是 TF；③ 人类微缺失病 scRNA 数据集中在脑类器官。
  • 【思路】 选一个"关键基因是 TF 且在数据里有表达"的病。
  • 【方法】 初选 22q11.2DS + TBX1（TF）→ 实测 TBX1 在脑里不表达 → pivot 到 Williams + GTF2I（脑表达 TF）。
  • 【结果】 22q11.2DS 脑数据无法扰动（TBX1 仅 15/9293 细胞）；Williams + GTF2I 可行（GTF2I 表达于 82% 细胞）。
  • 【不足】 只做了 Williams 一个病（原计划 2+ 病）；未覆盖"单一主效基因"型病（Angelman/UBE3A、Smith-Magenis/RAI1）；工具对非 TF 关键基因适用面窄。
第 2 步：确定细胞类型
  • 【问题】 脑类器官是多细胞类型混杂（16 个 cluster），非单一细胞类型；缺细胞类型注释。
  • 【思路】 聚类后按 cluster 分别建 GRN；分析时做疾病 vs 对照的整体对比。
  • 【方法】 6 样本合并（96969 细胞）→ QC → 归一化 → HVG（3000）+ 强制保留 Williams 区段基因 → PCA/UMAP/Leiden 聚类（16 cluster）。
  • 【结果】 96969 细胞 × 3016 基因，16 cluster，GTF2I 确认高表达。
  • 【不足】 未注释具体细胞类型（哪种神经元/前体）；疾病 DE 是混合细胞类型的 bulk 对比，可能被"细胞类型组成差异"污染；未聚焦 GTF2I 最相关的细胞亚群。
第 3 步：患者单细胞数据归因
  • 【问题】 SCimilarity 是单遍编码器（无级联）；归因 ≈ 表达（机械冗余）；归因 ≠ 因果（实测 r=0.02）；预测性测试证实归因无独立预测力。
  • 【思路】 用归因看"疾病里哪些基因的重要性变了"，作为候选来源。
  • 【方法】 SIGnature + SCimilarity + IG 归因（5000 患者 + 5000 对照）→ 差异归因（WS − CTRL）。
  • 【结果】 差异归因 ≈ 差异表达（r=0.949）；疾病信号 = 神经元分化基因（NEUROD2/6、SOX5、NFIA 等）；删失基因自身归因≈0 变化。
  • 【不足】 归因只给"重要性排序"，不给因果、不给方向，且基本是差异表达的镜像、无独立信息。
第 4 步：候选基因列表
  • 【问题】 归因给出的候选是"下游受影响程序"，不是"可扰动靶点"；候选多数不是 TF，无法用 CellOracle 验证。
  • 【思路】 从差异归因/差异表达提取候选，并与 CellOracle 结果交叉比对。
  • 【方法】 取 |Δ归因| 最大的基因 + CellOracle"被过表达拉回"的 top 基因，求交集。
  • 【结果】 候选 = 神经元分化程序（NEUROD2/6、SOX5、NFIA、ZEB2、BCL11B…）；CellOracle 与 SIGnature 两个独立方法收敛到同一批基因（交叉验证，本通路最硬的结果）。
  • 【不足】 候选未经过"可成药/可扰动"筛选；候选基因与"治疗靶点"之间的因果链未建立。
第 5 步：模拟扰动后状态验证
  • 【问题】 ① CellOracle 只能扰 TF，候选多数不是 TF；② 单基因扰动 vs 多基因缺失不匹配；③ 删失基因自身 DE≈0，扰动效应弱。
  • 【思路】 用 GTF2I（文献公认的脑表型主效基因）做敲低/过表达，看能否复现/逆转疾病转录组。
  • 【方法】 CellOracle GRN（预构建 hg38 promoter base GRN）→ fit_GRN_for_simulation → simulate_shift（GTF2I 敲低→0、过表达→2×）。
  • 【结果】 GTF2I 敲低 r=−0.046、过表达 r=+0.072（都 ≈0，无系统信号）；但 top 被恢复基因方向对（SOX5/NEUROD2/NFIA 等神经基因被过表达往上拉）。
  • 【不足】 单基因扰动抓不到整个多基因缺失的转录组；无法扰动非 TF 基因（GTF2IRD1/ELN/LIMK1…）。

4. 贯穿全程的三个根本不足

  1. 翻译层盲区（最致命）：本项目药物是 RNA binder（蛋白层上调），而所有 mRNA 模型（SCimilarity/CellOracle/GEARS）都假设"mRNA↔蛋白耦合成立"——药物恰好人为打破这层耦合，归因和扰动都打在错误的一层，模型从结构上看不见药效。

  2. 单基因 vs 多基因错配：微缺失病是多基因剂量敏感，而归因排序 + 单基因 TF 扰动都是单基因视角，只能抓到疾病信号的零头。

  3. 删失基因稳态 mRNA 层面"隐身"：实测删失基因（GTF2I 等）的表达和重要性在患者里几乎不变（DE≈0、Δ归因≈0）——单倍不足效应在稳态 mRNA 上测不到，整条"从 mRNA 数据找靶点"的路都有天花板。

5. 当时的结论与建议

以下为原报告的历史判断，引用前须结合第 1 节的证据边界。

结论：这条通路在"转录层、单一主效 TF、有表达、单一细胞类型"的理想条件下是通顺的（归因→候选→扰动验证，且两工具能交叉收敛）；但在本项目真实条件（翻译层 RNA binder + 多基因单倍不足 + 非 TF 关键基因 + 混合脑类器官）下，每一步都撞上结构性天花板。

最硬的正面资产：候选基因列表（神经元分化程序：NEUROD2/6、SOX5、NFIA、ZEB2、BCL11B）被两个独立工具交叉验证——可作为 iGEM 干实验结论，但须诚实标注它只是"相关/候选"，不是"因果/可成药靶点"。

建议：

  • 选病优先"单一主效 + 脑表型 + 剂量敏感"（如 Angelman/UBE3A、Smith-Magenis/RAI1）。
  • 若坚持 mRNA 工具，须明确"转录层补偿 ≈ 翻译层补偿"的假设，并注明 G 自身 mRNA 读数是盲区。
  • 翻译层药效的最终验证，仍需蛋白组/湿实验，mRNA 工具只能做"候选生成"。

SIGnature Genentech 的归因框架，给 SCimilarity 等模型算每个基因的重要性
单细胞基础模型（FM） 在超大单细胞数据上预训练的神经网络，学到的嵌入能代表细胞状态

单倍不足（haploinsufficiency） 两个等位基因丢了一个，剩下 50% 剂量不够用而致病
剂量补偿 把剩下的等位基因上调（转录或翻译），补回接近 100% 剂量
主效基因 一个病里起主要致病作用的基因（相对"乘客基因"而言）

差异表达（DE） 疾病 vs 健康的基因表达差异（最经典的找差异基因方法）
单遍编码器 只做"输入→嵌入"一次前向的模型，无法预测下游变化（无级联）
转录层 / 翻译层 基因表达的两个层次：转录产生 mRNA，翻译产生蛋白
RNA binder / SINEUP 结合 RNA 特定区域、上调其翻译的元件（本项目的药物机制）
