## 质询回答

### 质询 #0 — scRNA-seq 思路的根本可行性

**回答**：scRNA-seq 在筛选管线中的正确角色是**辅助验证层**，不是核心发现引擎。

理由来自四层证据：

| 证据层 | 发现 | 含义 |
|---|---|---|
| 项目内部 (E3/E4/E6/E8) | 归因≈DE、GEARS 域外、mRNA 补偿 | scRNA-seq 不能独立发现靶点 |
| 文献 benchmark (Schmid 2025) | 所有 CNV caller 对 <3Mb 不可用 | scRNA-seq 不能自动发现缺失区间 |
| 文献综述 (NRDD 2023) | Perturb-seq 全部分类为癌症/免疫 | 没有面向发育神经基因的因果工具 |
| 本次 DE 分析 | mRNA 补偿状态可测量、逐基因可变 | scRNA-seq 可辅助验证但不能独立排序 |

**但本次 DE 分析揭示了一个之前被低估的价值**：scRNA-seq 可以定量测量缺失区间内**每个基因的 mRNA 补偿状态**（WS/CTRL ratio）。这是一个 HPA/gnomAD/ClinGen 都无法提供的信息维度。补偿状态与你管线的 SINEUP 治疗逻辑直接相关：

- **完全补偿**（ratio ≈ 1.0，如 GTF2I）→ mRNA 正常但蛋白质可能仍不足 → **SINEUP 的理想靶标**
- **部分补偿**（ratio ≈ 0.7–0.9）→ mRNA 部分下降 → 蛋白质可能也下降 → 需要 SINEUP 但可能需要更大的上调幅度
- **无补偿**（ratio ≈ 0.5）→ mRNA 直接反映半剂量 → 翻译可能也减半 → 也可能需要 SINEUP

**Mode C 的重新定位**：从"全栈筛选模式"改为"数据库筛选 + scRNA-seq 补偿验证"。核心排序不依赖 scRNA-seq；scRNA-seq 作为增强层，在候选基因已通过 L1-L3 排序后，提供"该基因是否适合 SINEUP 靶向"的额外信息。

### 质询 #1 — 逐基因排序的核心假设是否成立？

**回答**：部分成立，需要加两个保护机制。

1. **表型分组**（已在 v2 架构中设计）：按 HPO/ClinGen 表型维度分组，组内排序。这样 ELN（心血管#1）不会和 GTF2I（神经#1）在同一框架下竞争。

2. **新增——"主效基因稀疏性警告"**：当以下条件同时满足时，在报告顶部标注 ⚠️ 警告：
   - 区间基因数 > 20
   - 排名 #1 的基因与其他前 N 个基因的证据分数差距不大（< 1 个标准差）
   - ClinGen 仅覆盖 < 20% 的区间基因
   
   警告措辞："该区间可能存在多个表型贡献基因，单一排名不应被解译为'唯一的因果基因'。建议对前 N 个候选进行正交验证。"

**管线不掩盖多基因协同效应的可能性**。Mode D 输出中增加一个独立章节"多基因协同假设"——如果多个基因同时满足高约束 + 相关表型 + 表达可行性，建议考虑组合靶向的实验设计。

### 质询 #2 — 证据金字塔是否在筛"正确的目标"？

**回答**：两个目标有时分离，管线需要识别这种情况并相应降权。

**对"隐性致病基因悖论"的具体处理**（结合质询 #4）：

新增一个**隐性致病基因过滤器**（在 L0 和 L1 之间）：
- 从 OMIM/ClinVar 获取已知隐性致病基因列表
- 如果一个基因被标记为**纯隐性**（biallelic pathogenic variants cause disease）且 gnomAD pLI > 0.9 → 标记为"⚠️ 隐性致病——杂合缺失可能无表型效应"
- 在 L3 排序中将其权重降低（pLI 贡献减半），但保留其在证据面板中的原始值供用户审查

**对"组织特异性低约束 TF"的补充**：
- HPA 组织表达可行性（v2 中已设计）部分解决了这个——如果一个基因在疾病相关组织中完全不表达，它不可能在那些组织中产生表型后果
- 结合 mRNA 补偿状态：如果某个组织特异性 TF 在脑类器官中 mRNA ratio ≈ 0.5（无补偿），它在脑中更可能不是主效基因（因为你期望主效基因的机制在该组织中发挥作用）

---

### 质询 #3 — 权重设定的依据？

**回答**：承认主观性，采用 LOO 调权作为客观校准，但标注限制。

**三层策略**：

1. **默认权重**（主观但基于文献优先级）：
   - ClinGen HI（人工金标准）: 3
   - gnomAD LOEUF（机制正交于 ClinGen）: 2
   - gnomAD pLI（与 LOEUF 部分冗余）: 1
   - DeepLOF（与 gnomAD 信息源重叠）: 1（仅在 gnomAD 覆盖弱时激活至 2）

2. **LOO 调权**（客观校准）：
   - 当正对照基因 ≥ 3 个时，运行 LOO 调权
   - 当正对照基因 < 3 个时，标记"⚠️ 权重未经充分校准，排序结果对参数敏感"
   - WBS 实验中 LOO 失败（2 个对照 = 0% hit rate）→ 这个阈值在 v2 中将作为硬性条件

3. **权重敏感性分析**（新增输出）：
   - 在最终报告中增加一节："如果 ClinGen:gnomAD 权重从 3:2 变为 1:1，排名前 3 的基因为 [X, Y, Z]，排名变化为 [Δ]"
   - 给用户一个量化的"排名稳健性"指标

### 质询 #4 — gnomAD 系统性偏倚

**回答**：承认三个偏倚，逐一处理。

| 偏倚 | 处理 |
|---|---|
| **基因长度偏倚** | 在 L1 证据面板中新增"pLI 置信度"字段——短基因（CDS < 1000 bp）的 pLI 标注 ⚠️ "低统计效力" |
| **隐性致病基因悖论** | 如质询 #2 所述，OMIM/ClinVar 隐性致病基因过滤器，降权 |
| **人群结构偏倚** | 管线默认使用 gnomAD v4（含非洲/东亚人群代表性改善），输出中标注 gnomAD 版本号和主要人群组成 |

---

### 质询 #5 — ClinGen 覆盖盲区

**回答**：这是管线当前最严重的弱点。区分"无证据"和"证据表明不敏感"。

**三值标注**（替代当前的 NaN → 0）：

| ClinGen 值 | 含义 | 在排序中的处理 |
|---|---|---|
| 0, 1, 2, 3 | 已评级 | 按原权重处理 |
| **null** | 未评级——无人研究过 | 贡献 0（中性——不扣分），标记"未知" |
| **30** | "基因与隐性表型相关" | 贡献 0（中性），标记"隐性" |
| **40** | "无证据" | 贡献 0（中性），标记"无评级" |

**关键**：null/30/40 全部为中性（0 贡献），不扣分。v1 中将 null 视为 0 分（=no signal），这错误地惩罚了"研究不足"的基因。

**当 ClinGen 覆盖率 < 20% 时，管线在输出中标注**："ClinGen 仅覆盖该区间 N% 的基因。以下排序主要依赖 gnomAD 约束分数——这偏向'群体遗传学上不耐受'的基因，可能漏掉'组织特异性、未被 Curators 研究过但表型重要的'基因。"

### 质询 #6 — DeepLOF 循环推理风险

**回答**：确认风险。DeepLOF 仅在以下条件下激活：

1. **L1 证据弱**：基因在 gnomAD 中覆盖弱（pLI 缺失或短基因）
2. **DeepLOF 的信息增量 > 0**：该基因的 DeepLOF 分数与 gnomAD pLI 的相关性 < 0.7（即不是完美共线——意味着有独立信息）
3. **权重上限**：DeepLOF 权重不超过 1，即使 LOO 调权也不会让其权重超过 gnomAD 权重的一半

**另一个实验性想法**（给 iGEM 评委展示前瞻性思维）：未来的版本中，可以训练一个新的深度学习模型，使用**与 ClinGen/gnomAD 独立的信息源**（如蛋白质结构预测、跨物种保守性、蛋白质互作网络），避免循环推理。但这不是当前 Cycle 的目标。

### 质询 #7 — 从排名到实验决策

**回答**：管线输出中新增"实验验证建议"章节。

**实验建议的三部分**：

**Part A: 第一候选的验证路径**
```
基因 X 排名 #1
├─ 证据: ClinGen HI=3, gnomAD pLI=1.0, pct_expr=82%, mRNA ratio=0.995
├─ 建议验证:
│ 1. qPCR 确认缺失断点是否确实包含 X（在患者 gDNA 上）
│ 2. Western blot 确认蛋白质是否不足（翻译层未补偿）
│ 3. 如果蛋白不足 → 设计 SINEUP-X → 细胞模型测试蛋白恢复
└─ 预期: 如果蛋白不足被 SINEUP 恢复 → 验证成功
```

**Part B: 第一候选失败时的切换策略**
```
如果基因 X 的蛋白质正常（即翻译也补偿了）→ 切换到备选
├─ 备选 1: 基因 Y（排名 #2，证据等级 ★★☆）
├─ 备选 2: 基因 Z（排名 #3，证据等级 ★★☆）
└─ 切换标准: ≥ 1 项正交证据（pLI/ClinGen/表达）INDEPENDENT OF 基因 X
```

**Part C: 排名不确定时的建议**
```
如果前 3 个候选的证据等级相同（★★☆），且排名受权重选择敏感：
├─ 不推荐直接靶向
├─ 建议先做: 在患者细胞系中做单个基因的 shRNA rescue 实验
│  （恢复每个候选基因的表达 → 看哪个恢复表型最好）
└─ 用这个正对照结果更新管线的权重
```

## 由此导出的管线 v2.1 优化

基于以上八个问题的回答，提出以下具体改动：

### 优化 1: 新增"mRNA 补偿状态"维度（源自质询 #0）

当 scRNA-seq 数据可用时，在 L1 后、L3 前新增：
- 计算每个缺失区间基因的 WS/CTRL mRNA ratio
- 标注补偿状态：完全补偿 (0.95-1.05) / 部分补偿 (0.7-0.95) / 无补偿 (0.5-0.7) / 无法判断（低表达）
- 在 L3 证据面板中作为单独一列："mRNA 补偿状态"
- 不参与加权排序（避免和 DE 偏倚重叠），但标注 SINEUP 靶向潜力

### 优化 2: 隐性致病基因过滤器（源自质询 #2, #4）

- L0.5: 隐性致病基因过滤器（新增模块 `filter_recessive.py`）
- 读取 OMIM/ClinVar 隐性致病基因列表
- 对重叠的候选基因标记 `recessive_disease: true`
- 在 L3 中降权（gnomAD pLI 贡献 ×0.5）

### 优化 3: ClinGen 三值标注（源自质询 #5）

- `merge_evidence.py` 中 ClinGen 字段改为三值标注
- null/30/40 → 中性（不扣分），明确的 0 → 视为"有证据表明不敏感"
- 输出中显式区分

### 优化 4: 权重敏感性分析（源自质询 #3）

- `consensus_v2.py` 新增 `--sensitivity` 模式
- 输出"权重稳健性"矩阵：默认权重 vs ±1 变化后的排名变化

### 优化 5: 实验验证建议生成器（源自质询 #7）

- 新增 `report.py` 的"实验建议"章节
- 包含 Part A/B/C（如上）

### 优化 6: Mode D "主效基因稀疏性警告"（源自质询 #1）

- 当满足条件时自动生成警告
- 当 ClinGen 覆盖率 < 20% 时自动生成覆盖警告
