## 二、本次实验流程

### 输入
`outputs/cnv/candidates.csv`：**35 个威廉姆斯综合征（WBS）7q11.23 缺失区间基因**，来自上一轮 CNV 工作流（已知临床区间 chr7:72.7–74.8 Mb，GRCh38）。

### 数据源下载
| 数据源 | 版本 | 说明 |
|---|---|---|
| ClinGen | 2026-09-05 快照 | 基因剂量敏感性人工评级（HI 0–3） |
| gnomAD | v2.1.1 | pLI / LOEUF（oe_lof_upper）约束 |
| HPA | v23 consensus | 肝/肾（下载版本只含这两器官列） |
| HGNC | 最新 complete set | 符号→HGNC ID 别名映射 |

### Layer 0：归一化
- 35 个符号 → **34 个解析成功**（97%），1 个失败：`ENSG00000289346`（candidates.csv 里的一个未命名 novel gene，无 HGNC 符号）。

### Layer 1：证据整合（含本轮修复的 4 个真实数据问题）
1. **ClinGen**：TSV 头部有 5 行 `#` 注释 → `skiprows=5`；列名含 `#Gene Symbol` → 去 `#`。
2. **ClinGen 用基因符号而非 HGNC ID** → 用 HGNC 别名表映射（1524/1528 映射成功）。
3. **ClinGen 重复 PMID 列名** → 去重列。
4. **ClinGen 的 30/40 分数**（"基因与隐性表型相关"/"无证据"，不是剂量敏感评级）→ 转为缺失，避免被当作高分。
5. **gnomAD 用 `gene` 列** → 直接符号匹配（27/35 = 77%）。

### 连接率（关键诊断）
| 数据源 | 连接率 | 说明 |
|---|---|---|
| ClinGen HI | **14%**（5/35） | WBS 区间基因大多没有被 ClinGen 评级过 → 人工金标准覆盖不足 |
| gnomAD | **77%**（27/35） | 8 个缺：多为 SPDYE 重复基因家族、novel gene |
| HPA | **97%**（34/35） | 肝、肾两器官 |

### Layer 3：共识排序（consensus_v2 --tune）
- 归一化：rank（排序百分位）
- 权重：ClinGen 3 / gnomAD LOEUF 2 / pLI 2（配置默认）
- HPA 惩罚：每器官 >1.0 TPM 扣 2，上限 -4
- Borda 对照排序 + Spearman 一致性 + LOO 正对照调权

## 三、结果解读

### 3.1 按证据强度的生物学梯队（证据层原始数据，最可信）

**第一梯队 — 群体约束强信号（pLI > 0.9 且 LOEUF < 0.35）：**

| 基因 | pLI | LOEUF | 功能提示 |
|---|---|---|---|
| **BAZ1B** | 1.000 | 0.109 | 染色质重塑（BAF 复合物亚基），WBS 表型候选 |
| **CLIP2** | 0.99997 | 0.196 | 微管结合，神经发育 |
| **LIMK1** | 0.9993 | 0.225 | WBS 认知表型经典候选 |
| **GTF2I** | 0.9959 | 0.270 | **本项目 pivot 主效基因**（E7 验证 82% 细胞表达） |
| **STX1A** | 0.9785 | 0.293 | 突触 SNARE 蛋白 |
| **GTF2IRD1** | 0.9004 | 0.329 | GTF2I 家族，WBS 表型相关 |

**第二梯队 — 人工确认但约束信号弱：**

| 基因 | ClinGen HI | pLI | LOEUF | 解读 |
|---|---|---|---|---|
| **ELN** | **3**（确认剂量敏感） | ~0 | 0.871 | WBS 心血管表型主效基因（文献金标准），但群体约束测不出——机制差异 |

### 3.2 与项目的交叉验证
- **GTF2I 排名第 4（证据层）** — 与 E7 完全一致（脑类器官 82% 表达、是 TF、CellOracle 可用）。
- **ELN"高 ClinGen 低约束"** — 单倍剂量不足机制多样性的教科书案例：重要 ≠ 群体突变清除强。
- **LIMK1 高约束** — 与文献认知（认知表型候选）吻合。

### 3.3 consensus_v2 排序结果（带警示）
`--tune` 后的排序：FZD9(#1) > FKBP6(#2) > TMEM270 > SPDYE… > ELN(#9) > BAZ1B(#10) > CLIP2(#11) > GTF2I(#21) > LIMK1(#20)

**⚠️ 该方法学问题（必须说明）：**
1. **rank 归一化把小样本排名扭曲了**：FZD9/FKBP6 的 pLI 极低（0.002 / 0.000001），在 rank 方向映射下被当成"最不耐受"排到最前——理由是"低 pLI 更不耐受"只在全基因组比例分布下有统计意义，35 个基因的小集合里第 1/第 35 的差距被放大成固定分数差，与生物学无关。
2. **HPA 惩罚过度**：BAZ1B 肝表达 23.4 TPM → 被扣 2 分，把强约束基因压到第 10。
3. **LOO 调权失败（0%）**：35 基因里只有 ELN + GTF2I 两个正对照（TBX1/KCTD13/RAI1 不在 WBS 区间内，属预期），top-N=10 对样本量过大，调权无统计效力。
4. **加性排序 vs Borda 排序 Spearman ρ ≈ 0.23**：两法高度不一致——主要因 Borda 不含 HPA 惩罚 + rank 伪影，恰好暴露了配置的不合理处。

### 3.4 诚实结论
> **证据层（原始数据）比共识层（当前配置）更可信。**
> 90% 的有效信号来自"ClinGen ELN=3 + gnomAD 高 pLI/低 LOEUF 六个基因"这一小撮证据；共识层当前的排序主要由配置瑕疵（rank 归一化 + HPA 惩罚 + 调权重参数）驱动，而不是生物学。

## 四、方法学反思（哪些结果可信 / 不可信）

| 结果 | 可信度 | 理由 |
|---|---|---|
| BAZ1B/CLIP2/LIMK1/GTF2I/STX1A/GTF2IRD1 高约束 | 🟢 高 | 两个独立 gnomAD 指标一致 |
| ELN ClinGen=3 | 🟢 高 | 人工金标准 |
| FZD9/FKBP6 排名第一 | 🔴 不可信 | rank 归一化伪影 |
| ELN 排名第 9 | 🟡 部分 | ClinGen 强但约束弱，机制真实但排序被 HPA 惩罚压低 |
| LOO 调权结果 | 🔴 无效 | 对照数 2 远不足 |

### 当前管线的已知短板
1. ClinGen 覆盖不足（WBS 区间仅 14% 有评级）→ 多数基因只能靠 gnomAD。
2. HPA 只有肝/肾两器官（下载版本限制），脑表达缺失 → 无法直接做 E6 型组织可行性检查。
3. AI 层（DeepLOF 等）未接入 → 无法覆盖"ClinGen 缺失 + gnomAD 弱"的基因（如 ELN 型）。
4. 上游 CNV 工作流只配置了 WBS 一个区间；8 种病其余 7 个区间待补（坐标需逐个核实）。

## 五、下一步（优先级排序）

1. **修排序合理性（低投入高回报）**：
   - `consensus_v2.normalize` 从 `rank` 改为 `raw`（或 zscore）；
   - HPA 惩罚降权（`per_organ_weight: -1`）或对高 pLI 基因豁免；
   - 关闭或下调 LOO 调权（对照数太少时直接报"无效"，不产出误导排名）。
2. **补 HPA 脑表达**：换下载源拿到全 51 组织版本，补 `hpa_brain_expr` 列，恢复 E6 型可行性检查。
3. **AI 层试点**：等 ClinGen 缺失 + gnomAD 弱的那批基因需要佐证时，再接 DeepLOF（条件权重模式，先验已写好）。
4. **补全 8 病区间表**：22q11.2、16p11.2、17p11.2、15q13.3、1p36、2p15p16.1 等，坐标逐条以 DECIPHER/ClinGen 核实（GTF2I 坐标教训）。
