3.2 博客遗漏的经典（本次补遗）

Geneformer —— 注意力机制 in silico 扰动（博客遗漏 ★）

  • 论文：Nature 2023, DOI 10.1038/s41586-023-06139-9
  • 代码：HuggingFace ctheodoris/Geneformer（geneformer/in_silico_perturber.py）
  • 年份/团队：2023，Christina V. Theodoris（Gladstone/Broad/DFCI，原 Broad 博后）
  • 核心思想：基于 ~3000 万（现 >1 亿）单细胞转录组的上下文感知双向 Transformer 基础模型。in silico 扰动通过「删除某基因的 rank-value token 并量化其余基因嵌入的位移」来模拟基因敲除/激活，无需任何扰动训练数据。
  • 扰动类型：基因敲除/抑制（in silico deletion/overexpression），零样本
  • 训练数据规模：Genecorpus-30M（~30M 细胞，现扩展至 >100M）
  • 基准表现与局限：在心肌病剂量敏感基因预测等任务上显著优于替代方法；局限是「删除 token」的近似并非真正的表达变化模拟，输出是嵌入位移排序（靶点优先级）而非定量表达谱，不直接做转录组水平预测。

CellOracle —— GRN 线性传播 in silico 扰动（博客遗漏 ★）

  • 论文：Nature 2023, DOI 10.1038/s41586-022-05688-9
  • 代码：morris-lab/CellOracle
  • 年份/团队：2023，Morris/Cahan 组（Washington Univ / JHU）
  • 核心思想：两阶段——(1) 用 scATAC-seq + scRNA-seq 经贝叶斯/Bagging 岭回归推断细胞类型特异的 GRN；(2) 沿 GRN 边做线性传播，模拟 TF 敲除/过表达后的细胞身份位移（输出为低维向量场而非绝对表达）。
  • 扰动类型：转录因子敲除/过表达
  • 训练数据规模：仅需未扰动野生型多组学数据（无需扰动训练）
  • 基准表现与局限：在斑马鱼胚胎发生、造血 TF 扰动上正确复现表型变化；局限是线性传播假设、输出限于细胞身份位移（2D 向量场）而非全转录组定量预测。

4.1 流匹配 / 扩散生成（2024–2026）

CellFlow —— 流匹配生成扰动表型（博客遗漏 ★★，任务点名）

  • 论文：bioRxiv 2025, DOI 10.1101/2025.04.11.648220
  • 代码：theislab/CellFlow（文档 cellflow.readthedocs.io）
  • 年份/团队：2025，Fabian J. Theis 组（Helmholtz Munich + TUM，联合 Treutlein/Regev/Camp）
  • 核心思想：用流匹配（flow matching）学习控制分布→扰动分布的连续速度场，把扰动响应建模为分布到分布的映射，天然捕获细胞异质性。支持组合药物、剂量、时序。
  • 扰动类型：细胞因子刺激、药物（单药/组合）、基因敲除、形态素组合
  • 训练数据规模：高内涵表型筛选数据（药物/遗传/细胞因子）；可扩展至全胚胎发育扰动、类器官协议
  • 基准表现与局限：在多种表型筛选上准确预测未见条件响应，并完成「虚拟类器官筛选」；局限是需配对的控制/扰动批量数据，未见扰动的纯零样本泛化弱于基础模型路线。

Squidiff —— 扩散模型预测响应（博客遗漏 ★）

  • 论文：Squidiff: Predicting cellular development and responses to perturbations using a diffusion model（PMC12407682）
  • 代码：见论文（diffusion autoencoder + DDIM）
  • 年份/团队：2025
  • 核心思想：扩散自编码器（semantic encoder + 条件 DDIM），在语义潜空间做扩散，预测跨细胞类型的转录组响应。
  • 扰动类型：细胞分化、基因扰动、药物处理
  • 基准表现与局限：跨三种任务（分化/基因/药物）验证稳健性；局限是扩散采样慢、条件组合外推有限。

PerturbDiff —— 函数式扩散（博客遗漏 ★，2026 预印）

  • 论文：arXiv 2602.19685
  • 代码：论文声明「code and data 即将公开」
  • 年份/团队：2026 预印
  • 核心思想：把「细胞分布」本身（经核均值嵌入 kernel mean embedding 表示）当作扩散的随机变量，而非把单个细胞当随机变量；MM-DiT 块对控制/扰动 token 流做联合注意力。显式建模分布级变异性，克服传统模型「单一固定响应分布」假设。
  • 扰动类型：基因/药物
  • 基准表现与局限：在既有数据集上达 SOTA 且对未见扰动泛化更强；局限是预印、代码未公开、核均值嵌入计算开销。

4.2 Arc Institute 虚拟细胞模型（2025–2026）

State —— 首代 set-transformer 虚拟细胞模型（博客遗漏 ★★★，任务点名）

  • 论文：bioRxiv 2025, DOI 10.1101/2025.06.26.661135
  • 代码：ArcInstitute/state
  • 年份/团队：2025，Arc Institute（Abhinav Adduri 等，合作 Stanford Leskovec、UCSF Gilbert/Konermann、Patrick Hsu）
  • 核心思想：跨物理尺度的 set-based Transformer，由两部分组成——状态转移模型（在细胞集合上学习扰动效应）+ 细胞嵌入模型（SE，State Embedding）。用双向注意力在细胞群体上建模，而非单细胞独立嵌入。用嵌入模型在「从未见过扰动的全新细胞上下文」中识别强扰动。
  • 扰动类型：遗传（CRISPRi/a）、化学（药物）、环境
  • 训练数据规模：>100M 扰动细胞（70 个细胞上下文）+ 167M 人观测细胞
  • 基准表现与局限：在 Tahoe-100M 上扰动效应判别提升 50%+、真 DEG 识别精度 2×；局限是 2025-06 发布、太新未经独立第三方验证。

Stack —— 上下文学习（in-context learning）虚拟细胞模型（博客遗漏 ★★★）

  • 论文：bioRxiv 2026, DOI 10.64898/2026.01.09.698608
  • 代码：ArcInstitute/stack
  • 年份/团队：2026，Arc Institute（Mingze Dong、Abhinav Adduri、Yusuf Roohani 等，合作 Yale）
  • 核心思想：tabular attention 架构，把细胞×基因矩阵分块作为输入单元，实现细胞内（基因间）与细胞间双重信息流。真正的上下文学习：推理时给一组带标签的 prompt 细胞集，即零样本预测未见扰动响应，无需任何权重更新/微调。
  • 扰动类型：化学、遗传、供体水平扰动
  • 训练数据规模：150M 统一预处理单细胞 + 55M 细胞 post-training（CellxGene + Parse PBMC）
  • 基准表现与局限：在 31 项 in-context 评测中 28 项排第 1（零样本扰动/供体/条件迁移）；发布 Perturb-Sapiens 图谱（513,870 细胞、28 组织、40 细胞类、201 扰动）。局限是 2026 预印、需 GPU 推理。

State 与 Stack 关系：State = 微调范式（对目标任务 fine-tune set-transformer）；Stack = 上下文学习范式（零权重更新）。二者互补，同属 Arc 虚拟细胞路线。

4.3 物理理论驱动（2025）

CIPHER —— 线性响应理论（博客遗漏 ★★）

  • 论文：bioRxiv 2025, DOI 10.1101/2025.06.27.661814（Goyal 组，Northwestern）
  • 代码：GoyalLab/CIPHER（PyPI: cipher-perturb）
  • 核心思想：统计物理的线性响应理论——响应 Δx = Σu，其中 Σ 是未扰动细胞的基因-基因协方差矩阵，u 是稀疏驱动向量。只靠基线涨落结构预测全转录组扰动结果，配 Bayesian（Horseshoe 先验）不确定度估计。
  • 扰动类型：基因敲低（CRISPRi）、激活（CRISPRa）
  • 训练数据规模：仅需未扰动控制细胞（无需任何扰动训练），11 数据集 / 4,234 扰动 / 1.36M 细胞验证
  • 基准表现与局限：合成网络上 R² 达 1.0；扰动识别 AUROC=0.92（超越传统差异表达指标）；消除基因-基因协方差使性能下降 11 倍，证明涨落结构是核心信息。局限是线性近似、对强非线性响应可能失效。

4.4 生成模型补遗（2023–2025）

SAMS-VAE —— 稀疏可加机制偏移 VAE（博客遗漏 ★）

  • 论文：NeurIPS 2023, arXiv 2311.02794
  • 代码：insitro/sams-vae
  • 年份/团队：2023（NeurIPS），insitro
  • 核心思想：扰动样本潜态 = 局部潜变量（样本特异性）+ 稀疏全局扰动潜变量之和；对每个扰动做稀疏化以得到可解耦、可组合的扰动特异潜子空间。
  • 扰动类型：药物/基因（含组合）
  • 基准表现与局限：在组合扰动任务上超越 CPA；局限是稀疏约束的调参、对大规模数据集扩展性。

PerturbNet —— 未见化学/遗传扰动预测（博客遗漏 ★）

  • 论文：Mol Syst Biol 2025, DOI 10.1038/s44320-025-00131-3
  • 代码：见论文（VAE + OT + ChemicalVAE 嵌入）
  • 年份/团队：2025
  • 核心思想：VAE（ZINB 似然直接建模原始计数）+ 最优传输，用药物嵌入（ChemicalVAE）与基因功能注释辅助预测未见化学/遗传扰动后的细胞状态分布。
  • 扰动类型：化学（药物）、遗传（CRISPRa/i）
  • 基准表现与局限：在未见化学扰动 R²/Pearson 上超越 chemCPA 与线性基线；对未见基因扰动显著优于先前方法。局限是依赖药物/基因功能注释的覆盖。

4.5 因果推理（2023，博客遗漏、任务点名）

CINEMA-OT —— 因果反事实匹配（博客遗漏 ★★）

  • 论文：Nat Methods 2023, DOI 10.1038/s41592-023-02040-5
  • 代码：vandijklab/CINEMA-OT（新版并入 scverse/pertpy）
  • 年份/团队：2023，van Dijk 组（Yale）
  • 核心思想：ICA 分解出混杂因子与治疗相关因子 → 在混杂空间做熵正则化最优传输（Sinkhorn）得到反事实细胞对 → 估计个体治疗效应（ITE）、响应聚类、归因、协同分析。
  • 扰动类型：细胞因子、病毒、药物（处理效应）
  • 训练数据规模：无监督，需配对控制/处理组
  • 基准表现与局限：在治疗效应估计任务上优于其他单细胞扰动分析方法；局限是回答「因果反事实」而非「表达谱预测」，与生成式预测工具是互补而非替代。

虚拟细胞能否承担药物效应模拟与基因扰动？— 文献调研与可行性判定

日期：2026-09-12 · iGEM SINEUP 微缺失剂量补偿项目 · 为「该块工作能否用虚拟细胞做」而作的文献调研 范围：AI 虚拟细胞（学得模型）+ 机制性全细胞模型（whole-cell / VCell）+ 数字孪生（本报告第三种含义） 关联：PROJECT_LOG.md（#0–#6）· 架构设计_v2_通用微缺失主效基因筛选管线.md · 前作《集成方案_L1证据层与现有平台融合.md》《融合操作手册_管线与VirtualCellTool按DBTL集成.md》 引文书目：见 outputs/literature/bibliography/virtual_cell_review_bibliography.md（DOI 验证状态逐条标注）

0. 摘要（先给判定）

核心判定：不可能，也不应该，把我们的「主效基因筛选 + SINEUP 剂量补偿靶向」交给虚拟细胞来做。 这不是能力保守——它恰好是领域在 2024–2026 反复自我证实的结论：

  1. 基因扰动模拟：转录组学扰动预测（GEARS、CellOracle、CPA、scGPT 微调）在独立基准上未超过简单线性基线（Nature Methods 2025），且存在”平均坍缩”（mean collapse）的系统性缺陷——这与我们 E3/E4（归因≈DE、r=0.02）、E11（GEARS 只覆盖 4/41 疾病基因）的挫折同构。换句话说：我们的负结果不是方法学失误，而是领域的墙。
  2. 药物/治疗效应模拟：单细胞药物响应（chemCPA/CPA）、蛋白层虚拟细胞（ProteinTalks）有进展，但全部依赖「该细胞状态曾在训练数据中出现过」。我们的治疗场景——胚系杂合微缺失 + RNA binder 翻译层上调——在公开 perturb-seq 数据中不存在，属于最困难的 out-of-distribution 情形。
  3. 机制性全细胞模型（Karr 式）：只对细菌/酵母等简单组织建成过，人类细胞可扩展性差、劳动密集（40 个基因的 M. genitalium 就需 28 个子模型）——对 22q11.2/7q11.23 这类区间 + 翻译层调节，不是可操作选项。
  4. 但它有一个合法的位置：作为 L3 机制假设生成器 + iGEM 演示/叙事层（虚拟细胞愿景本身是 iGEM 评委可感知的 framing），以及——我们自己的「mRNA 补偿状态」维度（v2.1）恰好是几乎所有虚拟细胞模型都缺失的独特输入，这可以成为贡献点而非短板。

推荐路径：用领域基准为自己的负结果正名（基准对比小实验，低成本、高叙事价值）；把虚拟细胞严格限制为假设层；真实投资留给「蛋白层验证 + 可泛化基准跟上之后再说」。

1. 术语澄清：我们说的「虚拟细胞」指哪三种

谱系 代表 原理 成熟度 适合回答的问题

2. 基因扰动模拟（in-silico perturbation）：现状与墙

2.1 四类主流方法

  1. 图增强的转录响应预测：GEARS（Roohani et al., Nat Biotechnol 2023）——用基因-基因关系知识图 + 深度学习预测未见过组合扰动的转录结果。我们已实测：解释性有限，训练图缺失疾病基因（4/41）。
  2. GRN 推断 + 虚拟扰动：CellOracle（Nature 2023）——从未扰动的野生型 scRNA/多组学推断基因调控网络，做 in silico TF 扰动模拟细胞身份变化。我们已用作 L3：GTF2I 扰动全局≈0（与 E8 的 mRNA 隐身一致）。
  3. 组合扰动自编码器：CPA（Mol Syst Biol 2023）——组合式扰动（基因×药物×剂量×细胞类型），可做剂量-响应曲线和未见组合的 OOD 预测。chemCPA（NeurIPS 2022）把药物分子结构编码进相同框架，可从 bulk HTS 迁移到单细胞。
  4. foundation model 微调：scGPT（Nat Methods 2024）等预训练于大规模 scRNA，官方教程含扰动预测微调；scGenePT（2024）尝试用语言模型文本嵌入替代表达数据——结论是语言嵌入并不必然更好。

2.2 领域自我证伪（与我们的 E3/E4/E11 同构）

  • Nature Methods 2025 基准（“Deep-learning-based gene perturbation effect prediction does not yet outperform simple linear baselines”）：5 个 foundation models + 2 个其他深度学习模型，在单/双基因扰动转录变化预测上，没有一个超过刻意简化的线性基线。同一作者的 bioRxiv 版结论完全相同。
  • 平均坍缩（mean collapse）：高相关分数常常是模型在输出全体均值而非扰动特异信号——假阳性 + 不可解释，这解释了为什么”排第一”的模型在正对照上失稳。
  • npj Digital Medicine 2025 综述在临床转化章节原话确认：“深度学习基因扰动效应预测尚未超过简单线性基线”，并把它列为临床转化前必须攻克的验证缺口之一。

这意味着：我们 E3/E4 的”归因≈表达量、预测不了因果”、E11 的”扰动模型覆盖不到疾病基因”不是孤立挫折，而是整个领域 2023→2025 的基线的确认。iGEM 叙事上这是一个极好的”诚实负结果 = 领域级发现”素材。

2.3 乐观的新支线（2026，均为早期）

  • AetherCell（2026）：生成式 foundation model，试图统一临床 RNA-seq 与扰动密集实验数据（解决”data-utility paradox”），目标虚拟细胞扰动 + in vivo 药物发现。仍在概念验证。
  • TwinCell（2026，bioRxiv）：“大型因果细胞模型”，从癌细胞系扰动数据学上游调控因子（而非预测扰动结果），宣称可泛化到患者衍生细胞。逆向因果建模——与我们”谁驱动表型”的问题更贴近，但尚未有第三方基准。
  • StateXDiff（2026）：细胞状态上下文多模态扩散做单细胞扰动预测，聚焦 OOD——回应平均坍缩问题，报告仍是 preprint。

小结：基因扰动模拟 2023–2026 的主线从”乐观预测”转向”诚实基准 + 聚焦 OOD”；没有任何一个模型能可信地预测稳态不表达/被补偿基因的行为（我们工作最需要的场景）。注意 [2.2] 与 [2.3] 是相互对照的：前者是审稿后正式基准，后者是未经第三方验证的 preprint，引用时应区分。

3. 药物/治疗效应模拟：现状

3.1 单细胞药物响应（学得模型）

  • chemCPA（NeurIPS 2022）：编码药物分子结构，从 bulk RNA HTS 迁移学习到单细胞药物响应；含剂量作为条件变量。
  • CPA：除组合扰动外，能生成剂量-响应曲线——对药物效应是直接的可用方法，但同样限于训练分布内。
  • scDrugMap（2026，工具+基准）：为单细胞药物响应的 foundation model 提供大规模横跨癌症类型/药物类别/方案种类的基准，强调”现有 FM 在分布外药物上并不稳”。

3.2 蛋白层虚拟细胞（直击我们的”翻译层盲区”）

  • ProteinTalks（Nature 2026）：对乳腺癌细胞系做约 3.8×10⁷ 条时间分辨蛋白丰度测量，训练蛋白层虚拟细胞。这是我们翻到的唯一一个把扰动响应建在蛋白层（而非 mRNA 层）的操作性虚拟细胞——恰好针对 E6/E8 的”mRNA 隐身、翻译层才是靶”问题。局限：仍是癌细胞系 + 单类扰动，且未覆盖胚系杂合剂量场景。

3.3 机制性药物效应模拟（不是细胞，是”细胞内的机制仿真”）

  • VCell / PhysiCell 平台 + VCBA（Virtual Cell-Based Assay）：虚拟细胞机制仿真平台，报告用于毒理学（如 predicted drug-induced liver injury、cardiotoxicity，hiPSC-CM 虚拟细胞预测 doxorubicin 卡迪毒性）。方向：药物”副作用”而非药物”对被剂量不足基因的修复”。
  • 数字孪生/虚拟患者（QSP）：Pompe 酶替代疗法用定量系统药理学数字孪生做 in silico 疗效对比，支持 FDA 式讨论——证明”剂量修复类治疗”在机体/药动学粒度是可以被机制模型模拟的。但泵病是”缺酶→补酶”，我们是”缺基因→上调自身蛋白”，粒度与机制都不同。

3.4 治疗逻辑相关的最贴近文献（gene-dosage 修复的机制建模）

  • SINEUP 技术本身：Indrieri 2016（Sci Rep）证明合成反义 lncRNA SINEUP 能在体内上调目标蛋白表达，挽回”剂量不足基因”；后续综述（2021）明确把 haploinsufficiency（单倍剂量不足）列为 SINEUP 首要治疗场景。但没有任何文献把 SINEUP 效应放进虚拟细胞。
  • 剂量补偿电路建模（合成生物学视角）：miRNA 剂量补偿电路（bioRxiv 2024）、“Equalizers”复制数缓冲电路（Nat Commun 2021）做的是外源表达剂量的精确控制——它们是”如何补偿”的工程答案，不是”预测被补偿基因行为”的模型。

4. 对我们管线的可行性判定矩阵

管线环节 能否用虚拟细胞 判定 理由
L0/L1 遗传学剂量证据（ClinGen/gnomAD/HPA） ❌ 不用，也不该用 保留现状 遗传学证据与转录组正交，恰是绕开 E3/E8 的关键；虚拟细胞(转录组学)没有额外信息
L2 候选基因扰动效应预测（“若 XX 剂量减半，细胞内会怎样”） ⚠️ 假设层可用，证据层不可用 仅作 L3 机制反注 领域基准未过线性基线 + mean collapse + 训练分布不含”胚系杂合缺失+被补偿基因”

SINEUP 治疗效应预测（上调后蛋白/剂量恢复多少） ❌ 现有虚拟细胞做不到 数据不存在 无公开”microdeletion + RNA binder”perturb-seq；翻译层盲区只要 ProteinTalks 触及，且其分布亦不含本场景

iGEM 交付/演示 ✅ 建议 叙事资产 AIVC 愿景 + 我们”补偿状态”维度可交互可视化，虚拟细胞作为框架性演示而非科学管线

一句话：虚拟细胞在我们的管线里应该出现在下游的”假设与展示”和旁路的”毒性筛查”，而不是上游或中游的”发现与排序”。

一、结论先行（3 行）

  1. 首选主链路 = Python 端 pertpy（scverse）+ Scanpy/AnnData：pertpy 内建 Mixscape、Augur、CINEMA-OT、扰动空间（perturbation space）等扰动专用方法，原生读写 h5ad，与 Scanpy 的 UMAP/热图/DEG 绘图无缝衔接，是「扰动前后细胞状态变化」的一站式分析+可视化框架。[1][2][23]
  2. 交互式共享与人工探索交给 CELLxGENE：CELLxGENE Annotate 直接读 h5ad、百万级细胞流畅交互、按扰动/基因着色与筛选，是「把结果交给湿实验合作者/审稿人自己翻」的成熟方案；其 Discover Census 还提供全球公开扰动/疾病单细胞数据做对照与背景。[7][8][21]

三、三大类工具逐一说明

类别 1：通用单细胞可视化生态

1.1 Scanpy / AnnData

  • 定位：Python 端最主流的单细胞分析+绘图工具箱，与 anndata 共同开发，覆盖预处理、可视化、聚类、轨迹推断与差异表达检验。[17]
  • 数据规模：按需内存处理，稀疏矩阵表达，十万到百万级细胞可行（依赖具体步骤与硬件）。[unverified]
  • 生态/安装：pip install scanpy，依赖 anndata、scipy、numba、matplotlib 等；属 scverse 生态。[17]
  • 能否直接读 h5ad：原生读写 h5ad（h5ad 即 AnnData 的磁盘格式）。[25]
  • 扰动效应展示方式：sc.pl.umap（按扰动标签着色/分面）、sc.pl.heatmap、sc.pl.dotplot、sc.pl.matrixplot、sc.pl.rank_genes_groups_*（DEG 热图/点图/矩阵图/轨道图）——DEG 用 sc.tl.rank_genes_groups(method="wilcoxon") 计算后直接可视化。[13]

1.2 Seurat

  • 定位：R 端最主流的单细胞分析工具箱，Satija 实验室维护；mixscape 最初即作为 Seurat 功能发布。[11][24]
  • 数据规模：Seurat 对象（.rds / 新版 .qs2），内存内处理；稀疏矩阵表达。[unverified]
  • 生态/安装：install.packages("Seurat")（CRAN），R ≥ 4.x；依赖 Matrix、ggplot2 等。[unverified]
  • 能否直接读 h5ad：不能直接读 h5ad，需经 SeuratDisk（ReadH5AD）或 zellkonverter 转换；Seurat 原生格式为 rds/qs2。[unverified]
  • 扰动效应展示方式：DimPlot（UMAP 按扰动/靶基因着色）、FeaturePlot（按基因表达着色）、VlnPlot（扰动前后基因表达小提琴图）；mixscape 专用链路 CalcPerturbSig → RunMixscape → PlotPerturbScore（扰动评分密度图）+ LDA 降维可视化扰动特异性簇。[11][12]

1.3 iSEE

  • 定位：Bioconductor 的通用交互式数据浏览器，Shiny 实现，聚焦 SummarizedExperiment / SingleCellExperiment 对象。[9]
  • 数据规模：中型单细胞数据（数万～数十万细胞），依赖预先计算好的降维与注释，不适合百万级实时交互。[unverified]
  • 生态/安装：BiocManager::install("iSEE")，需 R ≥ 3.5、Bioconductor ≥ 3.7。[10]
  • 能否直接读 h5ad：不能直接读 h5ad；需先将 h5ad 经 zellkonverter 转成 SingleCellExperiment。[unverified]
  • 扰动效应展示方式：多面板（reduced dimension plot 按扰动/细胞类型着色、column data plot、heatmap、table），面板间动态联动选择、代码追踪（可复现），适合把「扰动前后」的细胞元数据（obs/colData）与表达矩阵并置对照。[9][10]

类别 2：扰动专用分析可视化

2.1 pertpy（scverse 扰动分析框架）★ 核心推荐

  • 定位：面向大规模单细胞扰动实验的端到端框架，覆盖数据整合、元数据注释、扰动距离计算、扰动响应分析。[1]
  • 内建扰动专用方法（每个都带 plot 接口）[2]：
    • Mixscape：计算扰动签名（perturbation signature）、用高斯混合模型把细胞分为「KO（真敲除）/ NP（未扰动）」并做 LDA 可视化；带 plot_barplot / plot_perturbscore（评分密度）/ plot_heatmap / plot_lda / plot_violin。[2]
    • Augur：用分类器（随机森林/逻辑回归）按细胞类型训练「区分处理 vs 对照」的模型，以 AUC（分类）或 concordance（连续）排序各细胞类型对扰动的响应强弱。[2][16]
    • CINEMA-OT：因果推断 + 最优传输，分离混杂与扰动效应，输出反事实细胞对与治疗效应矩阵（de.X）及低维嵌入，带 plot_vis_matching（匹配可视化）、synergy（联合扰动协同）、generate_pseudobulk。[23]
    • 扰动空间（Perturbation space）：把每个扰动聚合为一个表示（pseudobulk/centroid/distance/分类器嵌入/聚类），支持对照差分、最近扰动查询、剂量响应等，直接产出「扰动 × 扰动」的比较矩阵用于热图/聚类展示。[2]
  • 生态/安装：pip install pertpy 或 conda install -c conda-forge pertpy；CINEMA-OT/Sccoda 等需 pertpy[jax]，DEG 接口需 pertpy[de]。[27] 论文：Heumos et al., Nature Methods 2025（DOI 10.1038/s41592-025-02909-7）。[1][28]
  • 能否直接读 h5ad：原生读写 AnnData/h5ad，与 Scanpy、muon 无缝衔接。[1][23]
  • 扰动效应展示方式：UMAP 按扰动着色、Mixscape 评分密度图、Augur 细胞类型排序、CINEMA-OT 匹配流图、扰动空间差分热图——几乎覆盖题目要求的所有展示形式（UMAP 着色 / 扰动评分 / DEG 热图 / 轨迹对比）。

2.2 CINEMA-OT（独立包）

  • 定位：因果推断 + 最优传输的单细胞扰动效应识别，分离混杂因子与治疗相关因子，输出反事实细胞对与个体治疗效应，支持协同分析。[4][5]
  • 生态/安装：pip install cinemaot，Python ≥ 3.7；官方注明新版本已迁移到 pertpy 维护，建议经 pertpy[jax] 使用。[5]
  • 能否直接读 h5ad：操作 AnnData（经 scanpy/anndata）。[4][23]
  • 扰动效应展示方式：反事实匹配可视化（plot_vis_matching）、治疗效应空间 UMAP、协同评分 UMAP（按效应强度缩放点大小）。[23] 论文：Dong et al., Nature Methods 20(11):1769–1779 (2023)。[4][23]

2.3 scDesign3（扰动响应仿真/对照）

  • 定位：R 包「全能」单细胞数据仿真器，用参考数据集生成含不同细胞状态（细胞类型/轨迹/空间坐标）、多模态（表达/染色质/蛋白/甲基化）、复杂实验设计的 in silico 数据，可做扰动响应预测的基准/对照。[6]
  • 生态/安装：devtools::install_github("SONGDONGYUAN1994/scDesign3")，输入 SingleCellExperiment；并行计算主要面向 UNIX。[6] 论文：Song et al., Nature Biotechnology 42, 247–252 (2024)。[6]
  • 能否直接读 h5ad：输入为 SingleCellExperiment，h5ad 需经 zellkonverter 转换。[unverified]
  • 扰动效应展示方式：本身偏「生成/建模」而非「展示」，用 AIC/BIC 选模型、自带可视化函数；在「展示扰动前后状态变化」场景中作为仿真对照层（回答「扰动效应是否超过噪声基线」）。[6]

2.4 Augur（R 独立包）

  • 定位：优先排序「对扰动响应最强」的细胞类型，用随机森林分类器在交叉验证中量化处理 vs 对照的分子可分离性（AUC），支持跨条件差异优先排序（differential prioritization）。[14][15]
  • 生态/安装：R 包，输入为 features×cells 矩阵或 Seurat 对象；依赖 randomForest、glmnet、parsnip 等。[14] 论文：Skinnider et al., Nature Biotechnology (2020)，在 22 个数据集上优于基于 DEG 的方法。[15]
  • 能否直接读 h5ad：不能；需矩阵或 Seurat 对象。[14]
  • 扰动效应展示方式：细胞类型 AUC 排序条形图/点图、差异优先排序（∆AUC 置换检验）——回答「哪些细胞类型被扰动改变最多」，是「状态变化」的层级定位工具。[14][15]

2.5 DEG 火山图 / 热图方案（通用，扰动场景常用）

  • 机制：扰动 vs 对照的差异表达是「状态变化」最直接的证据；Python 端 sc.tl.rank_genes_groups(method="wilcoxon") 产出 logFC/p 值，热图用 sc.pl.heatmap（layer=“scaled”，RdBu_r 配色），火山图需自绘（matplotlib/plotly 散点 + 显著性阈值）。[13]
  • 注：Scanpy 没有内建「火山图」函数，DEG 结果需手动整理为 DataFrame 后用 matplotlib/plotly 绘制；这是该场景最常见的一个自定义绘图点。[unverified]

2.6 通路富集可视化（decoupleR + SCpubr）

  • 机制：DEG 只是「基因列表」，通路/转录因子活性更能说明「状态如何变化」。decoupleR 是 Bioconductor 的活性推断框架（支持 mlm/ulm/fgsea/viper/aucell 等方法，配 PROGENy 通路、CollecTRI TF 网络），输出每样本/细胞类型的通路活性分数。[18][20]
  • 展示：R 端 SCpubr 的 do_PathwayActivityHeatmap 把 decoupleR PROGENy 结果画成出版物级热图；也可用 pheatmap/ComplexHeatmap 自绘。[19] 论文：Badia-i-Mompel et al., Bioinformatics Advances (2022)（PMID 36699385）。[20]
  • 能否直接读 h5ad：decoupleR 输入为「矩阵 + 先验网络」，不直接依赖 h5ad；在 Python 端可用 decoupler 包对 AnnData 直接操作。[unverified]

类别 3：交互式平台

3.1 CELLxGENE Annotate / Discover Census

  • Annotate：CZ Biohub 的交互式单细胞浏览器，现代 Web 技术实现 ≥100 万细胞流畅可视化；pip install cellxgene（Python ≥ 3.10），cellxgene launch file.h5ad 直接读 h5ad，cellxgene prepare 可自动跑 PCA/近邻/UMAP/tsne/louvain。[7][8]
  • 扰动效应展示方式：左侧栏按扰动/细胞类型元数据着色，中心嵌入图点选，右侧栏查基因与基因集；可通过把「扰动前后」作为元数据列，交互式对照两状态下细胞分布与基因表达。[7]
  • Discover Census：全球公开单细胞数据的编程接口（TileDB-SOMA），可从 Python/R 按细胞/基因元数据低延迟查询，输出 AnnData/Seurat/SingleCellExperiment，CC-BY 4.0，每周+LTS 半年发布——用于找公开扰动/疾病数据集做背景对照。[21][22]

3.2 自建 Shiny / Streamlit 面板

  • Shiny 路线：iSEE（通用浏览，见 1.3）[9]；scRNAseqApp（Bioconductor，基于 ShinyCell，面向 Seurat 对象，一键把数据集发布成带筛选/绘图的 Web 应用）[31]；SeuratExplorer、SCRIB 等也提供 DEG 火山图（plotly）+ ComplexHeatmap 交互。[unverified]
  • Streamlit 路线：用 stlearn/plotly 把 AnnData 的 UMAP、基因表达、扰动着色做成 Web 面板，自由度最高、需自己写前端逻辑，适合最终交付/对内展示。[unverified]

五、针对「展示基因敲除或药物扰动前后细胞状态变化」的推荐组合

推荐一条 Python 主链路 + R/交互补充 的组合，覆盖「质控 → 扰动效应 → 定量证据 → 交互共享」四步：

推荐组合（按依赖顺序）

  1. Scanpy + pertpy（主链路，Python）
    • sc.pp 预处理 → sc.tl.umap → sc.pl.umap(color=["perturbation"]) 先看「扰动前后细胞在 UMAP 上是否分开」。[13][23]
    • 用 pertpy 的 Mixscape（pt.tl.Mixscape）区分真敲除 KO 与未扰动 NP 细胞，plot_perturbscore/plot_lda 展示扰动评分与扰动特异性簇——这是「敲除是否生效、哪些细胞真正被扰动」的关键质控。[2]
    • 用 pertpy 的 Augur（pt.tl.Augur）按细胞类型排序扰动响应强度，定位「哪类细胞状态变化最大」。[2][16]
    • 对药物/连续扰动，用 pertpy 的 CINEMA-OT（pt.tl.Cinemaot）得到反事实匹配与治疗效应空间，plot_vis_matching 展示「处理 vs 对照」的因果对应。[23]
    • DEG 证据层：sc.tl.rank_genes_groups(method="wilcoxon") → sc.pl.rank_genes_groups_heatmap 表达扰动后差异基因，火山图用 matplotlib/plotly 自绘（logFC × -log10 p）。[13]
  2. decoupler / decoupleR（通路/TF 活性，说明「状态如何变」）
    • 在 DEG 之上跑 PROGENy（通路）/ CollecTRI（TF）活性，用 SCpubr do_PathwayActivityHeatmap 或 pheatmap 出通路活性热图，把「基因列表」升级为「通路/调控机制变化」。[18][19][20]
  3. CELLxGENE Annotate（交互共享层）
    • 把含扰动标签、mixscape 分类、UMAP 嵌入的 h5ad 直接 cellxgene launch，交合作者/审稿人交互翻查；配合 Discover Census 拉公开对照数据。[7][8][21]

为什么这样组合（理由） - 一条 AnnData/h5ad 主链路无格式转换损耗：pertpy/Scanpy/CINEMA-OT/CELLxGENE 全原生读 h5ad，避免 Seurat↔︎h5ad 互转的摩擦。[1][25][7] - Mixscape 解决扰动实验特有的「敲除不完全/逃脱」混杂，Augur 与 CINEMA-OT 分别回答「哪个细胞类型」「因果效应多大」两个互补问题，覆盖题目要求的 UMAP 着色 / 扰动评分 / DEG 热图 / 轨迹对比全部展示形式。[2][23][15] - 通路富集补齐「机制」维度，CELLxGENE 补齐「交互」维度，四个工具各自只做最擅长的一层，不重叠。

若团队以 R 为主：改用 Seurat（mixscape 原生函数）+ iSEE（交互浏览）+ decoupleR/SCpubr（通路）等价替换，但 h5ad 需经 SeuratDisk 转换。[11][9][19]

六、值得深挖的开放问题

  1. 扰动评分（Mixscape）对药物扰动的适用性：Mixscape 最初为 CRISPR KO 设计（高斯混合模型分 KO/NP），对连续剂量药物扰动的直接可用性需验证；文献已指出对高 MOI 多 gRNA 场景存在统计量膨胀风险。[30]
  2. 扰动空间（perturbation space）的可视化成熟度：pertpy 提供了丰富的「扰动 × 扰动」聚合表示，但论文级（publication-ready）的出图规范与配色约定尚缺统一最佳实践。[2]
  3. 反事实匹配（CINEMA-OT）在组织/患者队列规模的可扩展性：方法在 PBMC 规模验证充分，但跨患者、跨批次的 confounder 建模（伪 bulk 扩展刚起步）仍需基准。[23]
  4. 预测 vs 观测的衔接：本任务为「展示扰动后实测状态变化」，与并行推进的「扰动响应预测」（CellOracle / scvi-tools / CellOT 等）如何共用同一可视化管线，尚未见统一方案。[unverified]

6. 痛点与未来方向（原文视角）

痛点（Pain points） 1. 泛化是硬伤：同一模型换到未见细胞上下文 / 未见扰动时性能显著下降，此前很多「SOTA」声明在严格 o.o.d 评测下不成立。 2. 大模型迷信不成立：scGPT/scFoundation 等基础模型在多个任务上并未优于简单线性模型（linearModel），甚至垫底。 3. 指标割裂：不同指标衡量的是不同信号（表达水平 vs delta vs DEG vs 分布），单一指标会高估模型，需多指标互补判断。 4. 大规模扰动数据稀缺，制约直接学习细胞间异质性。

未来方向（Future directions） 1. 细胞上下文嵌入：用 cell line embedding + 解耦表征，把「先验知识」注入模型以提升跨上下文泛化（作者方案 bioLord-emCell 是范例）。 2. 更真实的虚拟细胞：需更忠实刻画「异质性扰动响应」，而非只拟合平均趋势。 3. 标准化 benchmark 生态：论文提供了 Podman 可复现镜像 + 结果可视化网站（bm2-lab.github.io/scPerturBench-reproducibility），推动新工具接入对比。
