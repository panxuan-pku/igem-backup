# 虚拟细胞扰动工具选型建议报告

**结论（3 行）**
1. 博客基线（scPerturBench 23 方法，Nat Methods 2025）只覆盖「2024 前经典+基础模型」一代，遗漏流匹配/扩散、物理线性响应、Arc set-transformer 三条新方向。
2. 入门首选：CPA/GEARS 预测 → Scanpy+pertpy 可视化 → CELLxGENE 共享；前沿追踪：State/Stack、CellFlow、CIPHER。
3. 基础模型不自动占优、线性基线屡次反超——先看「有无扰动训练集」再选方法。

## 三、两条推荐路线

**入门首选组合**（易上手、文档全）：CPA 或 scGen(预测) → GEARS(多基因) → Scanpy+pertpy(可视化) → decoupler(通路) → CELLxGENE(共享)。全程 h5ad 无格式转换；免扰动数据、重解释用 CellOracle。

**前沿追踪清单**（2024–2026）：Arc State(>100M 细胞) 与 Stack(上下文学习、零样本免微调)；CellFlow(流匹配、虚拟类器官筛选)；CIPHER(线性响应、仅控制细胞)；PerturbDiff(函数扩散、预印)。跟踪 Arc Virtual Cell Challenge 2026(零样本跨细胞系 CRISPRi)。
