## 0. 结论先行（3 行）

1. 知乎原文《AI虚拟细胞干扰工具大测评》(zhuanlan.zhihu.com/p/2046991255708737596, 2026-06-07) 是一篇解读预印/论文 **"Benchmarking algorithms for generalizable single-cell perturbation response prediction"（Nature Methods 2025, 同济大学 Qi Liu 课题组 / bm2-lab）** 的科普测评文，核心在评测「扰动响应预测」工具的可泛化性。
2. 该基准覆盖 **27 个方法（23 个已发表方法 + 4 个基线）**、**29 个数据集**、**6 类评测指标（PCC/MSE/E-distance/Wasserstein/KL 散度/Common-DEGs 召回）**，分两大场景：细胞上下文泛化（i.i.d/o.o.d）与扰动泛化（遗传 CRISPR / 化学药物）。
3. 核心结论：多数模型「换到没见过的细胞上下文或扰动」时性能明显下滑，**大模型/基础模型并非自动占优**，简单线性模型（linearModel）常能追平甚至反超深度学习模型；作者提出用 **细胞上下文嵌入 + 解耦表征（bioLord-emCell）** 来提升泛化，并指出这是虚拟细胞模型走向实用的关键缺口。

## 3. 基准评测结论（作者依据的真实发现）

来源：Nature Methods 摘要 + scPerturBench README + 评测结果 CSV。

| 论断 | 依据 | 置信度 |
|------|------|--------|
| 模型在「未见细胞上下文」与「未见扰动」下性能普遍下滑 | 摘要：「concerns remain about their true efficacy… evaluated across diverse and previously unseen cellular contexts」 | 高（论文原文） |
| 基础模型不自动占优；简单线性模型有竞争力 | CSV：Adamson/ASCC3_1 单基因扰动任务中 linearModel Rank=2、scELMo Rank=1，而 scGPT Rank=13、scFoundation Rank=12 | 高（真实排名数据） |
| 大模型在部分任务反而垫底 | 同上，scGPT/scFoundation/scouter 在 Adamson 数据上排名靠后 | 高（数据） |
| 提升泛化的关键 = 细胞上下文嵌入 + 解耦 | 作者方案 bioLord-emCell：cell line embedding + disentanglement representation | 高（README） |
| 需要统一的、跨任务的标准评测 | 摘要：「the field lacks a rigorous, task-spanning assessment of model behavior」 | 高（论文原文） |

## 6. 痛点与未来方向（原文视角）

**痛点（Pain points）**
1. 泛化是硬伤：同一模型换到未见细胞上下文 / 未见扰动时性能显著下降，此前很多「SOTA」声明在严格 o.o.d 评测下不成立。
2. 大模型迷信不成立：scGPT/scFoundation 等基础模型在多个任务上并未优于简单线性模型（linearModel），甚至垫底。
3. 指标割裂：不同指标衡量的是不同信号（表达水平 vs delta vs DEG vs 分布），单一指标会高估模型，需多指标互补判断。
4. 大规模扰动数据稀缺，制约直接学习细胞间异质性。

**未来方向（Future directions）**
1. 细胞上下文嵌入：用 cell line embedding + 解耦表征，把「先验知识」注入模型以提升跨上下文泛化（作者方案 bioLord-emCell 是范例）。
2. 更真实的虚拟细胞：需更忠实刻画「异质性扰动响应」，而非只拟合平均趋势。
3. 标准化 benchmark 生态：论文提供了 Podman 可复现镜像 + 结果可视化网站（bm2-lab.github.io/scPerturBench-reproducibility），推动新工具接入对比。
