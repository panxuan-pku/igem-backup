# 虚拟细胞工具组合推荐 — iGEM 项目决策（2026-09-12）

> 依据：本文件夹四份调研（AI虚拟细胞扰动响应预测工具调研报告 / 单细胞扰动数据可视化工具调研报告 / 虚拟细胞工具选型建议报告 / 知乎解读）
> 约束：本项目管道事实——WBS 有 GSE283473 脑类器官（CTRL+WS，未配对扰动）；WHS 无 scRNA-seq；SINEUP = 激活方向 + 翻译层；已有 VCT 平台内建 CellOracle；GEARS 已证伪（4/41 覆盖）
> 一句结论：**预测/假设层 = CellOracle（保留）+ CIPHER（新增）+ linearModel（强制对照）；可视化 = pertpy + Scanpy + CELLxGENE；明确不选 State/Stack、CellFlow、PerturbDiff、Geneformer**

---

## 一、选型三过滤器（先对齐项目事实，再谈工具）

| 过滤器 | 项目事实 | 对选型的影响 |
|---|---|---|
| **F1 数据现实** | 无自有扰动训练集；WHS 零 scRNA-seq | 只选「仅需未扰动/野生型数据」的方法；淘汰需配对扰动数据者 |
| **F2 治疗方向** | SINEUP = 上调（activation），作用于翻译层 | 优先支持 CRISPRa 激活方向的工具；提醒 mRNA 层盲区 |
| **F3 领域铁律 + 诚实叙事** | E3/E4 归因≠因果；Ahlmann-Eltze 基准：深度模型未超线性基线 | linearModel 为强制对照；GEARS 转为负对照；虚拟细胞定位 = L3 假设 + 演示 |

## 二、推荐组合

### 2.1 预测/假设层（L3，机制反注用——不进 L1 排序）

| 角色 | 工具 | 选择理由 | 数据需求 | 局限（必须标注） |
|---|---|---|---|---|
| **主（保留）** | CellOracle | 已是 VCT 内建资产；仅需野生型多组学；TF 过表达方向 + 细胞身份位移输出 = 与 SINEUP 叙事同向 | 未扰动 scRNA+scATAC | 线性传播近似；输出非定量表达谱 |
| **新增候选** | CIPHER | 线性响应 Δx=Σu，**只用未扰动控制细胞**（WBS CTRL 可用）；明确做 CRISPRa 激活；AUROC 0.92 扰动识别；协方差可解释 | 未扰动控制细胞 | bioRxiv 2025 预印、无独立第三方验证；线性近似；mRNA 层 |
| **强制对照** | linearModel（及 control-mean） | 领域基准结论：深度模型未超过线性基线——任何 demo 必须并排 | 无 | — |
| **负对照** | GEARS | 我们已证明 4/41 疾病基因覆盖失败；保留为「我们测试过，结论与 Nature Methods 2025 一致」的叙事证据 | 扰动+图谱 | 自身就是负结果 |

### 2.2 可视化层

| 层 | 工具 | 作用 |
|---|---|---|
| 分析+绘图底座 | Scanpy/AnnData | UMAP 着色、DEG 热图（h5ad 原生） |
| 扰动专用一站式 | **pertpy**（Mixscape/Augur/CINEMA-OT/扰动空间） | Mixscape 敲除质控（KO/NP 区分）+ Augur 细胞类型响应排序 + 扰动空间差分热图 |

| 通路机制 | decoupler（Python 端，PROGENy/CollecTRI） | 把 DEG 升级为通路活性变化 |
| （保留） | 自建 VCT demo | iGEM 叙事 demo（PBMC3k+MS+GEARS），不做科学展示主链路 |

## 三、明确不选及其理由

| 工具 | 不选理由 |
|---|---|
| State / Stack（Arc） | 2026 preprint、需 GPU 推理；零样本强但无独立验证；主打敲低/药物方向，非激活；iGEM 时间线内收益不确定 |
| CellFlow | 需配对控制/扰动批量数据——我们没有 |
| PerturbNet / CPA / chemCPA 系 | 需扰动训练数据 + 化学/基因功能注释覆盖 |
| PerturbDiff | 2026 预印、代码未公开 |
| Geneformer | 输出嵌入位移**排序**（≈归因路线，正是 E3/E4 已排除的）；非定量表达谱 |
| Squidiff | 扩散采样慢、条件组合外推有限；无取代 CIPHER 的优势 |

## 四、必须写进 demo 的风险（与项目负结果一致）

1. **翻译层盲区依然适用**：CIPHER/CellOracle 均在 mRNA 层；被补偿基因（WBS：GTF2I ratio=0.995；WHS：NSD2 大概率同态）在线性协方差中可能"隐身"。→ 这正是一个可写的开放问题：「CIPHER 能否识别被补偿的剂量不足基因？」
2. **激活 ≠ 蛋白恢复**：所有工具预测的是转录响应，**预测不了 SINEUP 的蛋白恢复量**——蛋白层结论只能是湿实验。
3. **定位闭环**：虚拟细胞组合 = L3 机制假设生成 + 可视化；不参与 L1 遗传学排序，不作因果验证（与《文献调研_虚拟细胞药物效应与基因扰动》判定一致）。

## 五、落地路径（与 WBS 开发 / WHS 湿实验分工对齐）

- **WBS（有数据）**：用 GSE283473 的 CTRL 细胞跑 CIPHER 协方差（预测 GTF2I/ELN/BAZ1B/LIMK1 敲低与**激活**两个方向的转录响应）；并与已有 DE 分析（ratio 表）对照，检验「补偿基因是否隐身」；并排跑 linearModel 基线；CellOracle 反注 top 候选。
- **WHS（湿实验）**：CIPHER 只需求未扰动控制——WHS hiPSC（2025 已建系）或小鼠脑组织若拿到数据即可冷启动；预测 NSD2 激活后转录响应，作为湿实验方向的假设层。
- **可视化交付**：pertpy 出扰动空间热图 + Mixscape 质控 → CELLxGENE 共享链接进 iGEM wiki / 评委桌面。

## 六、一行叙事（可用于 wiki/答辩）

> "我们评测了当前所有主流的虚拟细胞扰动工具（含 2025–2026 前沿），结论与 Nature Methods 2025 正式基准一致——在无扰动训练数据的胚系剂量缺失场景下，线性响应模型（CIPHER）与 GRN 传播（CellOracle）是唯一可操作、可解释、且与 SINEUP 激活方向同向的假设生成器；我们仅把它们用于 L3 机制假设与演示，靶点判断与蛋白恢复验证始终锚定 L1 遗传学证据 + 湿实验。"
